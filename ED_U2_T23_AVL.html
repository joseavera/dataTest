Árboles AVL
El BST que se equilibra solo. Adelson-Velsky y Landis resolvieron en 1962 el problema que dejamos abierto la clase pasada: árboles que degeneran en listas.

El problema que dejamos abierto
¿Por qué el BST no siempre es eficiente?
BST degenerado — O(n)

Insertar 10,20,30,40 en orden: el árbol se convierte en lista. Buscar(40) necesita 4 comparaciones — O(n).

AVL equilibrado — O(log n)

AVL mantiene el árbol equilibrado automáticamente con rotaciones. Buscar(40) siempre ≤ log₂(n) comparaciones.

Dato histórico AVL son las iniciales de Adelson-Velsky y Landis, los dos matemáticos soviéticos que publicaron este algoritmo en 1962. Fue el primer árbol de búsqueda auto-balanceable de la historia.
Concepto central
El Factor de Balance (FB)

El Factor de Balance de un nodo es la diferencia entre la altura de su subárbol izquierdo y la del derecho:

FB(nodo) = altura(izquierdo) − altura(derecho)
−1
Equilibrado
El subárbol derecho es un nivel más alto que el izquierdo. El nodo está en equilibrio AVL.
0
Perfectamente equilibrado
Ambos subárboles tienen la misma altura. Situación ideal.
+1
Equilibrado
El subárbol izquierdo es un nivel más alto que el derecho. El nodo está en equilibrio AVL.
−2
Desbalanceado a la derecha
Se requiere rotación hacia la izquierda para restaurar el equilibrio.
|FB|≤1
Regla AVL
Un árbol es AVL si y solo si el FB de cada nodo está entre −1 y +1.
+2
Desbalanceado a la izquierda
Se requiere rotación hacia la derecha para restaurar el equilibrio.

Rotación doble Derecha-Izquierda (caso RL) — ocurre cuando FB = −2 y el hijo derecho tiene FB = +1.
Paso 1: rotación derecha sobre el hijo derecho (30 → 20 sube).
Paso 2: rotación izquierda sobre el nodo desbalanceado (10 → 20 sube como nueva raíz).

Paso 2: rotación derecha sobre el nodo desbalanceado (30 → 20 sube como nueva raíz).
El resultado es el mismo árbol equilibrado con dos rotaciones.

Código en C#
Implementación del AVL
Nota El AVL extiende el BST. La clase Nodo necesita un campo Altura. Insertar llama al mismo InsRec del BST pero agrega: recalcular altura, calcular FB y aplicar la rotación correspondiente.
AVL.cs — clase Nodo extendidaC# 
// El nodo de AVL agrega un campo Altura respecto al nodo de BST
class Nodo
{
    public int  Valor;
    public Nodo Izquierdo, Derecho;
    public int  Altura;  // ← nuevo: necesario para calcular el FB
    public Nodo(int v) { Valor = v; Altura = 1; } // toda hoja tiene altura 1
}
AVL.cs — funciones auxiliaresC# 
// Altura de un nodo (null = 0)
int Alt(Nodo n) => n == null ? 0 : n.Altura;

// Factor de Balance: izquierda - derecha
int FB(Nodo n) => Alt(n.Izquierdo) - Alt(n.Derecho);

// Actualizar la altura del nodo tras una modificación
void ActualizarAltura(Nodo n) =>
    n.Altura = 1 + Math.Max(Alt(n.Izquierdo), Alt(n.Derecho));
AVL.cs — rotacionesC# 
// ── Rotación simple derecha (caso LL) ────────────────────────
Nodo RotDer(Nodo y)
{
    Nodo x  = y.Izquierdo;   // x sube
    Nodo T2 = x.Derecho;      // hijo derecho de x se mueve
    x.Derecho    = y;          // y baja a la derecha de x
    y.Izquierdo  = T2;         // T2 pasa a ser hijo izquierdo de y
    ActualizarAltura(y);
    ActualizarAltura(x);
    return x;                  // x es la nueva raíz del subárbol
}

// ── Rotación simple izquierda (caso RR) ──────────────────────
Nodo RotIzq(Nodo x)
{
    Nodo y  = x.Derecho;      // y sube
    Nodo T2 = y.Izquierdo;    // hijo izquierdo de y se mueve
    y.Izquierdo  = x;          // x baja a la izquierda de y
    x.Derecho    = T2;         // T2 pasa a ser hijo derecho de x
    ActualizarAltura(x);
    ActualizarAltura(y);
    return y;                  // y es la nueva raíz del subárbol
}
AVL.cs — inserción con balanceoC# 
Nodo Insertar(Nodo n, int v)
{
    // 1. Inserción BST normal ─────────────────────────────────
    if (n == null) return new Nodo(v);
    if (v < n.Valor) n.Izquierdo = Insertar(n.Izquierdo, v);
    else if (v > n.Valor) n.Derecho = Insertar(n.Derecho, v);
    else return n; // duplicado: no insertar

    // 2. Actualizar la altura del nodo actual ─────────────────
    ActualizarAltura(n);

    // 3. Calcular el Factor de Balance ────────────────────────
    int fb = FB(n);

    // 4. Aplicar la rotación correcta si |FB| > 1 ─────────────

    // Caso LL: desbalanceado a la izquierda, hijo también izquierdo
    if (fb > 1 && v < n.Izquierdo.Valor)
        return RotDer(n);

    // Caso RR: desbalanceado a la derecha, hijo también derecho
    if (fb < -1 && v > n.Derecho.Valor)
        return RotIzq(n);

    // Caso LR: desbalanceado izq, pero el nuevo nodo es hijo derecho
    if (fb > 1 && v > n.Izquierdo.Valor)
    {
        n.Izquierdo = RotIzq(n.Izquierdo); // rotación izq sobre hijo
        return RotDer(n);               // rotación der sobre nodo
    }

    // Caso RL: desbalanceado der, pero el nuevo nodo es hijo izquierdo
    if (fb < -1 && v < n.Derecho.Valor)
    {
        n.Derecho = RotDer(n.Derecho); // rotación der sobre hijo
        return RotIzq(n);              // rotación izq sobre nodo
    }

    return n; // nodo equilibrado, no se necesita rotación
}
Clave Los pasos 1 a 4 de Insertar son siempre los mismos, en ese orden: inserción BST → actualizar altura → calcular FB → rotar si necesario. La recursión hace que el balanceo suba automáticamente desde el nodo insertado hasta la raíz.
