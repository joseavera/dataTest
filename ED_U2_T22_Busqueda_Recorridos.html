Tema 2.2 — Búsqueda
Buscar un valor en el BST
Por qué la búsqueda en BST es diferente a la búsqueda en lista

En una lista enlazada buscar el valor 60 obliga a recorrer todos los nodos desde el primero hasta encontrarlo o llegar al final. Con un millón de nodos, en el peor caso se hacen un millón de comparaciones.

En un BST, al llegar al nodo 50 sabemos que 60 es mayor, así que el subárbol izquierdo completo (20, 30, 40) queda descartado de inmediato. Con un árbol equilibrado de un millón de nodos, el máximo de comparaciones es aproximadamente 20.

Traza de Buscar(60) sobre el árbol de referencia:

50
60 > 50 — busco en el subárbol derecho. El subárbol izquierdo completo (20, 30, 40) queda descartado.
70
60 < 70 — busco en el subárbol izquierdo de 70.
60
60 == 60 — valor encontrado. Se devuelve true. Solo se hicieron 3 comparaciones.
Costo La búsqueda en un BST equilibrado cuesta O(log n) comparaciones en el caso promedio — exactamente la mitad del árbol se descarta en cada nivel. En el peor caso (árbol degenerado en lista) sigue siendo O(n), por eso los árboles AVL del siguiente tema garantizan el equilibrio.
Código en C#
Ejemplo 1 — Método Buscar
BST.cs — método Buscar C# 
// Agrega estos dos métodos a la clase BST del tema anterior

public bool Buscar(int valor)
{
    return BuscarRec(raiz, valor);
}

private bool BuscarRec(Nodo nodo, int valor)
{
    // Caso base 1: llegué a un null — el valor no existe
    if (nodo == null) return false;

    // Caso base 2: encontré el valor
    if (valor == nodo.Valor) return true;

    // Decisión binaria: izquierda o derecha
    if (valor < nodo.Valor)
        return BuscarRec(nodo.Izquierdo, valor);
    else
        return BuscarRec(nodo.Derecho, valor);
}

// Prueba en Main:
// arbol.Buscar(40)  → true   (existe en el árbol)
// arbol.Buscar(99)  → false  (no existe)
// arbol.Buscar(50)  → true   (es la raíz)
Patrón recursivo La estructura de BuscarRec es idéntica a la de InsertarRec: mismo caso base (nodo == null), misma decisión binaria (menor → izquierda, mayor → derecha). La diferencia es que en lugar de crear un nodo devuelve true o false.
Tema 2.2 — Los tres recorridos
InOrder, PreOrder y PostOrder

Los tres recorridos visitan exactamente los mismos nodos. Lo que cambia es el momento en que se procesa el nodo actual respecto a sus subárboles. Esa diferencia de orden produce secuencias completamente distintas y tiene aplicaciones específicas cada una.

InOrder
Izq → Nodo → Der
Se procesa el nodo entre los dos subárboles. En un BST siempre produce los valores en orden ascendente. Uso típico: listar o exportar datos ordenados.
20 30 40 50 60 70 80
PreOrder
Nodo → Izq → Der
Se procesa el nodo antes de bajar a los subárboles. El primer valor impreso siempre es la raíz. Uso típico: copiar o serializar la estructura del árbol.
50 30 20 40 70 60 80
PostOrder
Izq → Der → Nodo
Se procesa el nodo después de ambos subárboles. El último valor impreso siempre es la raíz. Uso típico: liberar memoria, eliminar el árbol nodo a nodo de forma segura.
20 40 30 60 80 70 50
Clave de memoria El prefijo indica cuándo se procesa el nodo: Pre-Order = antes (before) de los hijos. In-Order = entre los hijos. Post-Order = después de los hijos. El subárbol izquierdo siempre se visita antes que el derecho en los tres casos.

Código en C#
Ejemplo 2 — PreOrder y PostOrder
BST.cs — PreOrder y PostOrder C# 
// Agrega estos cuatro métodos a la clase BST

public void PreOrder()
{
    PreRec(raiz);
    Console.WriteLine();
}

private void PreRec(Nodo n)
{
    if (n == null) return;
    Console.Write(n.Valor + " "); // 1. proceso el nodo ANTES de bajar
    PreRec(n.Izquierdo);              // 2. subárbol izquierdo
    PreRec(n.Derecho);               // 3. subárbol derecho
}

public void PostOrder()
{
    PostRec(raiz);
    Console.WriteLine();
}

private void PostRec(Nodo n)
{
    if (n == null) return;
    PostRec(n.Izquierdo);             // 1. subárbol izquierdo
    PostRec(n.Derecho);              // 2. subárbol derecho
    Console.Write(n.Valor + " "); // 3. proceso el nodo DESPUÉS de subir
}
Código en C#
Ejemplo 3 — Programa completo con los cuatro métodos
Program.cs — BST completo C# 
using System;

class Nodo
{
    public int  Valor;
    public Nodo Izquierdo, Derecho;
    public Nodo(int v) { Valor = v; }
}

class BST
{
    private Nodo raiz;

    // ── Inserción ────────────────────────────────────────────────────
    public void  Insertar(int v) => raiz = InsRec(raiz, v);
    private Nodo InsRec(Nodo n, int v)
    {
        if (n == null) return new Nodo(v);
        if (v < n.Valor) n.Izquierdo = InsRec(n.Izquierdo, v);
        else if (v > n.Valor) n.Derecho   = InsRec(n.Derecho,   v);
        return n;
    }

    // ── Búsqueda ─────────────────────────────────────────────────────
    public bool Buscar(int v) => BusRec(raiz, v);
    private bool BusRec(Nodo n, int v)
    {
        if (n == null)          return false;
        if (v == n.Valor)       return true;
        return v < n.Valor
            ? BusRec(n.Izquierdo, v)
            : BusRec(n.Derecho,   v);
    }

    // ── Recorridos ───────────────────────────────────────────────────
    public void InOrder()   { InRec(raiz);   Console.WriteLine(); }
    public void PreOrder()  { PreRec(raiz);  Console.WriteLine(); }
    public void PostOrder() { PostRec(raiz); Console.WriteLine(); }

    private void InRec(Nodo n)
    { if(n==null)return; InRec(n.Izquierdo); Console.Write(n.Valor+" "); InRec(n.Derecho); }

    private void PreRec(Nodo n)
    { if(n==null)return; Console.Write(n.Valor+" "); PreRec(n.Izquierdo); PreRec(n.Derecho); }

    private void PostRec(Nodo n)
    { if(n==null)return; PostRec(n.Izquierdo); PostRec(n.Derecho); Console.Write(n.Valor+" "); }
}

class Program
{
    static void Main()
    {
        BST arbol = new BST();
        foreach (int v in new[] { 50,30,70,20,40,60,80 })
            arbol.Insertar(v);

        Console.Write("InOrder:   "); arbol.InOrder();
        // 20 30 40 50 60 70 80

        Console.Write("PreOrder:  "); arbol.PreOrder();
        // 50 30 20 40 70 60 80

        Console.Write("PostOrder: "); arbol.PostOrder();
        // 20 40 30 60 80 70 50

        Console.WriteLine($"Buscar(40): {arbol.Buscar(40)}");  // True
        Console.WriteLine($"Buscar(99): {arbol.Buscar(99)}");  // False
    }
}
