01 CONCEPTO
¿Qué es una pila?
La regla es simple:
último en entrar,
primero en salir.
🥞
La analogía perfecta
Las charolas de la cafetería. Siempre tomas la de arriba — la última que alguien colocó. No puedes sacar la del fondo sin quitar todas las de encima.
↩️
Ya la usas todos los días
Ctrl+Z en cualquier editor. La última acción que hiciste es la primera en deshacerse. Las acciones se apilan, y deshacer las desapila.
🌐
Botón «Atrás» del navegador
Las páginas visitadas se apilan. Cada vez que regresas, sacas la última página de la pila.

02 LIFO
el principio fundamental
Last In, First Out
Cada estructura de datos tiene una regla de orden. La pila usa LIFO. Entender esta regla es entender todo lo que Stack hace.
📥
Entraron en este orden
1° Tacos x2 ← fondo
2° Agua 500ml
3° Torta de jamón
4° Jugo naranja ← tope
📤
Salen en este orden
1° Jugo naranja ← sale primero
2° Torta de jamón
3° Agua 500ml
4° Tacos x2 ← sale al final
💡 El orden de entrada y el orden de salida son exactamente inversos. El primero en entrar es el último en salir. El último en entrar es el primero en salir.

03 OPERACIONES
solo necesitas tres
Push · Pop · Peek
Operación ¿Qué hace? En la cafetería Código C#
Push() Agrega un elemento encima del tope. La pila crece. Colocas una charola nueva encima de todas. pila.Push("Tacos");
Pop() Quita y devuelve el elemento del tope. La pila encoge. Agarras la charola de arriba — ya no está en la pila. string x = pila.Pop();
Peek() Solo mira el tope sin quitarlo. La pila no cambia. Miras qué charola está arriba sin tomarla. string x = pila.Peek();
Count Cuántos elementos hay actualmente en la pila. Cuentas las charolas apiladas. int n = pila.Count;
foreach Recorre todos los elementos del tope al fondo. Sin modificar. Revisas todas las charolas con los ojos de arriba a abajo. foreach(var p in pila){}
⚠️ Pop() y Peek() en una pila vacía lanzan InvalidOperationException. Siempre verifica pila.Count > 0 antes de llamarlos.

04 CÓDIGO
el mismo código de la clase
Stack<T> en C# — Ejemplo completo
Program.cs Cafetería IEDEP 
using System;
using System.Collections.Generic;

class Program
{
  static void Main()
  {
    Stack<string> pedidos = new Stack<string>();

    pedidos.Push("Tacos x2");
    pedidos.Push("Agua 500ml");
    pedidos.Push("Torta de jamón");
    pedidos.Push("Jugo naranja");

    // Ver el tope sin quitarlo
    Console.WriteLine(pedidos.Peek());

    // Quitar el último pedido
    string cancelado = pedidos.Pop();
    Console.WriteLine(cancelado);
    Console.WriteLine(pedidos.Count);

    // Ver todo
    foreach (string p in pedidos)
      Console.WriteLine(p);
  }
}
🖥 Salida en consola
Jugo naranja
Jugo naranja
3
Torta de jamón
Agua 500ml
Tacos x2
📌 Por qué esa salida
Peek() devuelve Jugo naranja — el tope — sin quitarlo.

Pop() saca Jugo naranja. Count baja a 3.

foreach recorre del tope al fondo: Torta → Agua → Tacos.
💻 Puedes abrir este código en tu Codespace y agregar Console.WriteLine después de cada línea para ver el estado en tiempo real.

05 DIFERENCIAS
la pregunta más frecuente
Pop() vs Peek()
Pop()
Quita el elemento del tope y lo devuelve. La pila cambia — Count disminuye en 1.
// Antes: [Agua, Torta, Tacos]
string x = pila.Pop();
// x = "Agua"
// Después: [Torta, Tacos]
// Count: 3 → 2 ✖
Peek()
Solo mira el tope y lo devuelve. La pila NO cambia — Count sigue igual.
// Antes: [Agua, Torta, Tacos]
string x = pila.Peek();
// x = "Agua"
// Después: [Agua, Torta, Tacos]
// Count: 3 → 3 ✔
🧠 Regla práctica: si solo quieres ver lo que hay arriba → Peek(). Si quieres sacar lo que hay arriba → Pop(). Confundirlos es el error más común.

06 COMPARATIVA
¿cuándo uso cuál?
Arreglo · LinkedList · Stack
📐
Array / int[]
arreglo fijo
Acceso por posición⚡ Directo
Insertar al inicio🐢 Mueve todo
TamañoFijo
Accede al últimoarr[n-1]
Úsalo cuando sabes exactamente cuántos elementos habrá y necesitas acceso directo por índice.
🔗
LinkedList<T>
lista enlazada
Acceso por posición🐢 Recorre
Insertar al inicio⚡ O(1)
TamañoFlexible
Accede al último.Last.Value
Úsalo cuando insertas y eliminas frecuentemente en cualquier posición y no necesitas acceso por índice.
🥞
Stack<T>
pila LIFO
Acceso por posición🚫 No aplica
Agregar al tope⚡ Push O(1)
TamañoFlexible
Accede al último⚡ Peek O(1)
Úsalo cuando SIEMPRE necesitas trabajar con el elemento más reciente. Ctrl+Z, historial, navegación.

07 ERRORES COMUNES
aprende de los errores más frecuentes
Los 3 bugs más comunes con Stack
🐛
Bug 1 — Usar Pop() cuando quieres Peek()
string x = pila.Pop(); — si solo querías ver el tope, acabas de quitarlo. La pila cambió sin que quisieras. Usa Peek() para solo observar.
🐛
Bug 2 — Tipo incorrecto en Push()
Declaras Stack<string> pero intentas pila.Push(42);. Error de compilación. Si necesitas números, declara Stack<int>.
🐛
Bug 3 — Pop() en pila vacía
Si la pila está vacía y llamas Pop() o Peek(): InvalidOperationException. Solución: siempre verifica primero.

if (pila.Count > 0) { string x = pila.Pop(); }
